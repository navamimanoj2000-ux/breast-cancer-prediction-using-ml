# breast-cancer-prediction-using-ml
Predictive Modeling Using Machine Learning is a Python-based project for breast cancer prediction using Logistic Regression, Decision Tree, and Random Forest algorithms. It includes data preprocessing, model training, evaluation, ROC analysis, confusion matrix visualization, and feature importance analysis using Scikit-learn.
# Predictive Modeling Using Machine Learning

A complete Machine Learning project for breast cancer prediction using classification algorithms in Python.

## Overview

This project predicts whether a breast tumor is benign or malignant using the Breast Cancer Wisconsin dataset from Scikit-learn. The project demonstrates the complete Machine Learning workflow including preprocessing, model training, evaluation, visualization, and prediction.

## Features

* Breast cancer prediction system
* Multiple Machine Learning algorithms
* Accuracy comparison between models
* Confusion matrix visualization
* ROC curve analysis
* Feature importance analysis
* Beginner-friendly implementation

## Algorithms Used

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Dataset

The project uses the built-in Breast Cancer dataset available in Scikit-learn.

Target Labels:

* 0 = Malignant
* 1 = Benign
